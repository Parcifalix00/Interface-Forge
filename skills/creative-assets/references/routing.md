# Asset routing

| Need | First choice | Check |
|---|---|---|
| Official logo | Supplied canonical file | Proportions, colors, authorized variant |
| UI icon | Existing adopted family | Metaphor, stroke/fill, readability, accessible name |
| Simple shape / vector graphic | Suitable deterministic SVG or components | Verified semantics and geometry |
| Informational diagram | Structured data/text plus available renderer | Data source and accessible equivalent |
| Illustration / photography | Authorized asset or available tool | Rights, cost, privacy, fidelity |
| Social preview | Brand-consistent composition | Required crop/aspect ratio, exact text |
| Control, form, table | Semantic code | Never a screenshot in place of the UI |

A local-first default does not authorize irrelevant visual approximations. If a photograph is required and there is no source or authorized generator, report the limitation. Do not add images merely because a provider is available.

Icons can have an interactive target larger than their visual mark. Avoid mixing icon families without a reason. For custom SVG, use a correct viewBox, coherent geometry, and adaptable properties. Do not introduce executable code.
