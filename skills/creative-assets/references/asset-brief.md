# Asset brief

Record: ID, UI role, available source, exact text, brand lock/revision, output and usage dimensions, aspect ratio, transparency, backgrounds, safe crop area, subject, style, and prohibited treatments.

Specify which properties must remain identical and which may change. For existing assets, use a real path. For variants, preserve a shared system and create meaningful differences rather than paraphrased prompts.

Distinguish graphic text baked into an image from interface text. Interface text remains code. Informational headings and numbers should not become unreadable or inaccessible because they were rasterized.

Before generation, verify the tool, required inputs, authorization for uploads, cost or quota, and destination. Without those facts, do not send remote requests.
