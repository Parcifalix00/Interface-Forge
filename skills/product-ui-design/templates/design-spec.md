# UI design specification

## Task and hierarchy
Primary task, essential content, secondary actions, navigation.

## Existing system
Components, tokens, fonts, icons, and assets to preserve.

## Layout
Wide, narrow, intermediate layouts, plus long-content behavior.

## States and interactions
For each component: default, loading, empty, error, selected, pending, disabled; add others only when relevant.

## Platforms and accessibility
Targets, safe areas, virtual/external keyboard, touch, focus, scaling, contrast, reduced motion.

## Acceptance criteria
Observable criterion, method, expected evidence, approved exception.
