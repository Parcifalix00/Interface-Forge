# Coordinator handoff

For substantial work, update the project's existing documentation or use `docs/interface-forge/` only when no suitable structure exists. Do not change the user's workflow.

Record: scope; inputs and sources; decisions; skills actually read; output paths; platforms/environments; tests and artifacts; limitations; and the next required action. The run log must not contain private reasoning, credentials, or unnecessary transcripts.

Keep three statements separate: "Implemented X", "Verified X in environment Y", and "Z still needs testing". An implementation that has not been tested on a required device may still be handed off for review with incomplete readiness. Do not call the device incompatible merely because evidence is missing.

If the user limits the task to an audit, deliver findings without hidden modifications. If the task already includes corrections, do not stop to request permission for every defect that falls inside the approved scope.
