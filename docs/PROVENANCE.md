## What was not imported

No upstream installers, SDKs, backends, executable templates, fonts, or Higgsfield generations are included. The workflows were rewritten for the five Interface Forge domains. MIT attribution is preserved inside each installable skill.

The suite does not adopt universal aesthetic rules about serif fonts, banned palettes, dark themes, number of accents, or icon families. It does not adopt automatic publishing, silent tool installation, hiding costs, or rules that discourage inspecting generated output.

An upstream recommendation that downplays object-access risk when UUIDs are used is not adopted. [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Insecure_Direct_Object_Reference_Prevention_Cheat_Sheet.html) requires object-level authorization regardless of identifier format. Interface Forge is not an offensive security product.

## Original additions

Versioned shared contract; routing without fictitious tool calls; explicit cost and privacy rules; Android/iOS phone/tablet baseline; browser-engine/device distinction; allowed evidence methods in reports; native scope without implicit ports; local tools for guarded installation, copy checks, and structural validation.

The brand lock remains declarative. Dependency invalidation concepts are review procedures, not an automated engine copied from Higgsfield. The package does not attribute Interface Forge-specific design choices to upstream sources.
