# Behavior cases

`routing-cases.json` contains positive, negative, and constraint-handling cases. Every case starts as `NOT_RUN`. Procedure and limitations are documented in [EVALUATION_PLAN](../docs/EVALUATION_PLAN.md).

These cases are not executed by unittest and do not require additional APIs. Manual execution in Codex uses the user's existing plan and tools. Preserve real evidence before changing the status of a case.
