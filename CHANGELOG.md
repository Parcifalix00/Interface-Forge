# Changelog

## 1.0.0 - 2026-09-18

First publishable release of Interface Forge: five skills, primary UI orchestration, shared contracts, a cross-platform baseline, templates, Codex metadata, local installation and QA tools, offline tests, evaluation cases, documentation, and MIT attribution.

The release includes stronger routing so `interface-forge` is consulted before specialist frontend skills for tasks that create, modify, or review a UI. Technical skills from other providers remain usable as implementation tools. The no em dash rule, the distinction between static checks, browser checks, emulators, and real devices, and the desktop, Android phone/tablet, iPhone, and iPad baseline are formalized when the target is not explicitly restricted.

Operational validation on Windows confirmed installation, Codex discovery, explicit orchestration, and implicit triggering in a small UI task. Real Android/iOS device testing remains separate and is not reported as executed.

Repository documentation, skill instructions, metadata, templates, evaluation cases, and local tool messages were standardized to English before first publication.
